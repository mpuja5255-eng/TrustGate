          📋 Dataset Transparency & Evaluation Methodology

          TOTAL TEST SAMPLES 100 Events
          ATTACK SAMPLES 40 Events (40%)
          NORMAL SAMPLES 60 Events (60%)
          TRAINING BASELINE 1,500 Samples
          ANOMALY THRESHOLD τ ≥ 0.65
          DATA LEAKAGE Zero (Held-Out)

          Methodology: Isolation Forest is an unsupervised algorithm trained strictly on 1,500 legitimate enterprise API transactions with zero attack contamination. Predictions are generated on a separate, held-out multi-scenario test stream containing both legitimate business calls and multi-step attacks, evaluated against independently maintained ground-truth labels.

          ⚠️

          Evaluation Warning & Scientific Notice

          "Performance metrics represent results on the specified evaluation dataset and do not guarantee equivalent performance in real-world deployment."

          Dataset Context: Evaluated on a balanced N=100 test stream (60 legitimate operations, 40 attack/anomaly events). In production environments with lower attack base-rates (<0.1%), absolute precision may decrease while false discovery rates increase.

          Hybrid architecture yielded a +15.0% Recall gain (from 80.0% to 95.0%) by intercepting reconnaissance sweeps (SCN-07) and unverified IP bursts (SCN-06). False positive rate increased by 15.0%, representing a realistic and sustainable analyst investigation queue overhead.
